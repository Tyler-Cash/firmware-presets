#$ DESCRIPTION: My standard analog VTX frequency/power table so every analog craft exposes the same band/channel/power naming in Configurator and on the OSD. Not applicable to HDZero builds, which don't use an RF vtxtable at all - see the OSD preset's HDZero/Analog NTSC display option instead.
#$ DESCRIPTION: This only sets the table and general VTX behavior - it deliberately does NOT set vtx_band/vtx_channel/vtx_power/vtx_freq, since the active channel is chosen per-flight, and does NOT set vtx_spi_bus, since that's board wiring, not a preference.
#$ DESCRIPTION: vtx_low_power_disarm is set to UNTIL_FIRST_ARM: on power-up the VTX stays at low/default power (safe at the pits) until the first arm, then it switches to and stays at full power even across later disarms, until the next power cycle. (The ALWAYS option instead drops back to low power on every single disarm, which is usually not what people want.)

# vtxtable
vtxtable bands 5
vtxtable channels 8
vtxtable band 1 BOSCAM A A CUSTOM  5865 5845 5825 5805 5785 5765 5745 5725
vtxtable band 2 BOSCAM B B CUSTOM  5733 5752 5771 5790 5809 5828 5847 5866
vtxtable band 3 BOSCAM E E CUSTOM  5705 5685 5665    0 5885 5905    0    0
vtxtable band 4 FATSHARK F CUSTOM  5740 5760 5780 5800 5820 5840 5860 5880
vtxtable band 5 RACEBAND R CUSTOM  5658 5695 5732 5769 5806 5843 5880 5917
vtxtable powerlevels 3
vtxtable powervalues 0 1 2
vtxtable powerlabels 25 100 MAX

set vtx_low_power_disarm = UNTIL_FIRST_ARM
set vtx_softserial_alt = OFF
set vtx_halfduplex = ON
