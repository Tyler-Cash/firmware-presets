#$ DESCRIPTION: My personal rates, aimed at a mix of freestyle and cinematic flying rather than pure racing. Uses QUICK rates (center sensitivity/max rate/expo interact into one continuous curve) rather than ACTUAL, which I found less prone to feeling twitchy near center at the default (zero expo) settings.
#$ DESCRIPTION: Roll/pitch max out at 900 deg/s, yaw at 650 deg/s - centers and expo tuned to feel punchy through normal stick movement without being twitchy. Derived and flight-tested via blackbox analysis on my Air65 across several sessions; roll/pitch center sensitivity and ceiling both checked out (full deflection actually reached 900 deg/s cleanly), yaw's center sensitivity was raised after blackbox data showed I was never getting anywhere near its ceiling even when trying to fly aggressively.
#$ DESCRIPTION: Also includes thr_expo for a bit of extra precision around hover without dulling throttle punch.
#$ DESCRIPTION: Deliberately excludes thr_mid: where your hover throttle % actually sits depends on that craft's thrust-to-weight ratio, so it varies craft to craft (mine sits around 30% on the Air65) - set it per-craft to match your actual hover point rather than copying a value tuned for a different airframe.

set rates_type = QUICK
set quickrates_rc_expo = ON
set roll_rc_rate = 42
set pitch_rc_rate = 42
set yaw_rc_rate = 55
set roll_expo = 15
set pitch_expo = 15
set yaw_expo = 15
set roll_srate = 90
set pitch_srate = 90
set yaw_srate = 65
set thr_expo = 15
